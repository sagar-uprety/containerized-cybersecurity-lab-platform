The organization's perimeter firewall was configured by a previous administrator to allow outbound web and DNS traffic. Management wants you to verify that internal services are properly protected from external access.

Your mission:

1. Use the browser terminal to inspect the lab network from the workstation.
2. Identify the firewall and the internal web server it should be protecting.
3. Test whether the internal server is reachable from the external network.
4. Inspect the firewall rules to understand how they work.
5. Determine whether the firewall actually blocks access as intended.
6. Fix any firewall rule issues you find on both IPv4 and IPv6.
7. Verify that outbound web browsing and DNS still work after your changes.
8. Run the portal check and record the result.
9. Complete the mandatory feedback form after ending the lab.

Useful paths:

- /etc/iptables/rules.v4 (IPv4 firewall rules)
- /etc/iptables/rules.v6 (IPv6 firewall rules)
- /lab/config/fw_internal_ip.txt (firewall internal IP)
- ~/SITREP.txt
